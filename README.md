# Chess Online Server v2

WebSocket-сервер для онлайн-шахмат.

## Render
- Runtime: Node
- Build: `npm install`
- Start: `npm start`
- Health: `/health`

Сервер рассчитан на публичный `wss://` endpoint.

## Протокол
Поддерживаются быстрый поиск, комнаты по коду, ходы, сдача, тайм-аут и согласованная пауза.

Пауза запрашивается игроком, а соперник должен принять её. Сервер ограничивает длительность 30–120 секунд и не позволяет использовать одну и ту же паузу повторно одним игроком.


## Чат матча
Сервер хранит последние 50 сообщений каждой активной партии и пересылает новые сообщения обоим игрокам. Максимальная длина сообщения — 300 символов. При переподключении история чата возвращается клиенту вместе с состоянием матча.

## Состояние матча
Матч хранится на сервере до завершения и ещё некоторое время после него. При временном отключении игрока запускается 60-секундное окно переподключения; часы замораживаются на это окно. Результат партии фиксируется сервером один раз.
