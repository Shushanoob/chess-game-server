# Chess Online Server v2

WebSocket-сервер для онлайн-шахмат.

## Render
- Runtime: Node
- Build: `npm install`
- Start: `npm start`
- Health: `/health`

Сервер рассчитан на публичный `wss://` endpoint.

## Протокол
Поддерживаются быстрый поиск, комнаты по коду, ходы, сдача, тайм-аут и согласованная пауза.

Пауза запрашивается игроком, а соперник должен принять её. Сервер ограничивает длительность 30–120 секунд и не позволяет использовать одну и ту же паузу повторно одним игроком.
